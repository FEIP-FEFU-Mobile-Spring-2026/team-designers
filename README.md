# 🐾 Розовая Пантера

Онлайн-магазин обуви

## 📱 О приложении

Мобильное приложение для покупки обуви с каталогом товаров, корзиной и оформлением заказа.

## 🛠 Стек технологий

- **Платформа**: Android
- **Язык**: Kotlin
- **Минимальная версия Android**: API 24 (Android 7.0)
- **Среда разработки**: Android Studio
